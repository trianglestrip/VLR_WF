# Git 提交规则

## 验证日期
2026-03-07

## 提交信息语言
- **所有 Git 提交信息必须使用中文（简体）**
- 提交信息应清晰、简洁地描述更改内容

## 编码设置
- Git 提交信息使用 UTF-8 编码
- 确保 Git 配置支持 UTF-8：
  ```bash
  git config --global i18n.commitEncoding utf-8
  git config --global i18n.logOutputEncoding utf-8
  ```

## 提交信息格式
- 使用简洁的中文描述更改的内容和原因
- 第一行：简短摘要（50字符以内）
- 空行
- 详细说明（如需要）

## 示例

### 好的提交信息
```
添加波前路径追踪核心数据结构

实现了 WavefrontPathState 和相关的光线追踪状态管理结构，
支持多次反弹的路径追踪计算。
```

### 避免的提交信息
```
update files
修复bug
WIP
```

## 注意事项
1. 避免使用纯英文提交信息
2. 确保提交信息有意义，描述"为什么"而不仅是"做了什么"
3. 使用 UTF-8 编码避免中文乱码
4. 提交前确认终端支持 UTF-8 显示
