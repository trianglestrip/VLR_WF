## 验证方法

### 方法1: 对话中提问
在任何时候询问：
```
"这次操作是否遵守了rules？"
"请检查是否符合workflow-preferences.md的要求"
```

### 方法2: 观察Shell调用
查看Shell工具的调用：
- ✅ 正确: 两次分开的Shell调用
  ```
  Shell(command: "cd build")
  Shell(command: "cmake ..")
  ```
- ❌ 错误: 使用&&连接
  ```
  Shell(command: "cd build && cmake ..")
  ```

### 方法3: 检查工具调用模式
- 多个独立任务应该在同一个响应中并行调用
- 依赖任务应该等待前一个完成后再执行

## 常见违规情况

### 1. PowerShell语法错误
**违规**: `cd build && cmake ..`
**原因**: PowerShell不支持`&&`
**修正**: 分两次执行或使用`;`

### 2. 串行执行独立任务
**违规**: 读取3个文件时分3次响应
**原因**: 未并行化
**修正**: 在一个响应中发起3个Read调用

### 3. 创建不必要的文档
**违规**: 创建新的PROGRESS.md
**原因**: 应该更新现有的docs/todo.md
**修正**: 使用StrReplace更新现有文件
